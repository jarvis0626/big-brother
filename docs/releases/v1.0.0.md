## What the app does

Big Brother helps you understand what a program is doing. Watch a running program, follow the helper programs it starts, browse a searchable activity timeline, and read findings linked to the exact supporting events. Save investigations for later or export a local report. Observation, scoring and ordinary explanations run on your computer.

To try it: open **Explore a replay → Investigation → Open replay**. This uses clearly marked sample data and never runs the programs described in the sample. Then try **Watch a process** to observe a program that is already open.

The README includes two GIF walkthroughs captured from the actual desktop app: opening a sample investigation, following findings to evidence, and exporting a report. [Read the illustrated guide](https://github.com/jarvis0626/big-brother/blob/v1.0.0/README.md).

## Installation and portable history

Open the installer and follow setup, or put the portable executable in a writable folder and open it. If you downloaded the combined ZIP, extract it first and choose `Installer` or `Portable`. The portable app saves history in `BigBrother-data` beside itself; keep that folder when moving the app.

Closing the window normally hides Big Brother in the system tray. Choose **Stop collection and exit** to quit completely. **Launch and watch** explicitly starts a selected executable; selecting a file alone does not run it.

## Limits

Packages are unsigned; Windows may show an unknown-publisher message. [SHA256SUMS.txt](https://github.com/jarvis0626/big-brother/releases/download/v1.0.0/SHA256SUMS.txt) verifies file integrity, not publisher identity.

A finding is a reason to investigate, not a malware verdict. A quiet findings list does not prove safety. The app does not block, quarantine or remove threats. Its behavioral model's malware-detection accuracy remains unmeasured; the separate static-feature classifier remains research-only. Broader file, Registry and DNS records require an existing configured Sysmon installation. Big Brother does not install that service automatically.
